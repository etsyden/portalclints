# Portal Clients

Client collaboration portal for project management, communication,
materials, approvals and project history.

## Project

Dental City Group — Редизайн сайта

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- NestJS
- PostgreSQL
- Prisma
- Redis

## Integrations

- ClickUp
- Google Drive
- Figma
- Telegram

## Runtime

Node.js 22.22.1

## Environments

- Local development
- Beget VPS production

## Security

Secrets and environment-specific configuration are stored outside Git.
The real .env file must never be committed.
